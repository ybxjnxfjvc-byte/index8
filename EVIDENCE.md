## Какие навыки подтверждаются

| № | Риск / навык | Проверяемый контроль |
|---:|---|---|
| 1 | Неавторизованный запрос | 401 + constant-time comparison |
| 2 | Mass assignment | Allow-list schema; extra fields → 400 |
| 3 | Большое тело | Body-size limit |
| 4 | Replay/повтор | Idempotency key / dedup для изменяющих операций |
| 5 | Секрет в клиенте | Секрет только в server-side env |

## Артефакты этого кейса

- `SECURITY.md` — scope и ограничения;
- `EVIDENCE.md` — карта доказательств;
- `security/docs/threat-model.md` — модель угроз;
- `security/tests/manual-security-checklist.md` — ручной сценарий проверки;
- Для углублённого исполняемого доказательства см. опорный практический кейс `index25`; текущий кейс не притворяется отдельным pentest-проектом.

## Не доказывается

- доступ к системам реальной организации;
- эксплуатация уязвимостей внешних сервисов;
- промышленная безопасность инфраструктуры;
- соответствие конкретному отраслевому стандарту без отдельного аудита.
