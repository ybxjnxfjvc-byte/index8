# Mini threat model — index8

## Scope

Публичный учебный кейс `Система обучения — Ренессанс Жизнь`, его статические файлы, браузерная сессия, локальное состояние и только те локальные лабораторные сервисы, которые лежат в этом репозитории.

## Assets

1. Целостность учебного контента и логики тренажёра.
2. Данные, вводимые посетителем в демонстрационные формы.
3. Состояние прохождения/результата, если оно сохраняется локально.
4. Конфигурация и секреты локальных лабораторных сервисов.
5. Целостность содержимого репозитория и публикации GitHub Pages.

## Trust boundaries

`visitor → browser DOM → local state → optional local lab`

`developer workstation → Git → repository → GitHub Pages`

## Risks and controls — API / авторизация / валидация запросов

| ID | Risk | Scenario | Control |
|---|---|---|---|
| T1 | Неавторизованный запрос | К endpoint обращаются без корректного bearer-токена | 401 + constant-time comparison |
| T2 | Mass assignment | Клиент присылает неожиданные поля | Allow-list schema; extra fields → 400 |
| T3 | Большое тело | Очень большой JSON расходует ресурсы | Body-size limit |
| T4 | Replay/повтор | Одна операция повторяется несколько раз | Idempotency key / dedup для изменяющих операций |
| T5 | Секрет в клиенте | Токен зашит в HTML/JS | Секрет только в server-side env |

## Residual risk

Статический публичный кейс не превращается в промышленное приложение только из-за наличия security-документации. Там, где отсутствует сервер, серверные меры показаны только в локальных учебных лабораториях и не выдаются за часть реальной инфраструктуры компании.
